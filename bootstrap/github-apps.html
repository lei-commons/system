Create the lei-commons GitHub Apps

Do these one at a time, with bootstrap/github-apps.sh running in Cloud Shell. For each App: click its button, click Create GitHub App on GitHub, copy the code= value from the address bar of the page GitHub opens, and paste it into the script. Codes expire after an hour.

No App gets the workflows permission, so no agent can change CI or deployment.

lei-commons-maker

Proposes changes: opens branches, pull requests and task issues. Cannot approve, merge into protected paths, or edit workflows.

Permissions: contents write, pull_requests write, issues write, metadata read

lei-commons-checker

Reviews what the maker proposes: reviews, checks and statuses. Never writes code.

Permissions: contents read, pull_requests write, checks write, statuses write, issues read, metadata read

lei-commons-guardian

Runs the conduct-policy and protected-path checks on every pull request.

Permissions: contents read, pull_requests read, checks write, statuses write, metadata read

lei-commons-release

Publishes the signed daily snapshots to the releases repository.

Permissions: contents write, metadata read
